RESEARCH EXPLORER: CHECKED, REPRODUCIBLE NATIVE WORKFLOWS

Open View > Research Explorer in Studio. It complements the existing Map
Explorer with ODE simulation, finite-time tangent diagnostics, native model
fitting and bounded native discovery experiments. Opening/resetting the panel,
editing a table, moving a parameter slider or generating a preview never runs
scientific code. Run / Recompute explicitly submits checked .p source to Studio's
single shared worker. Cancel uses that same worker and Ctrl+C remains available.

The Model table accepts real/Pentarnion state names, initial expressions and
ordered derivative expressions; every Pentarnion state retains five coordinates.
Parameters are runtime values. The solver tab controls the method, output times,
tolerances, wall budget, CPU thread cap and tangent settings. The fitting tab uses
a scalar/Pentarnion model expression, initial parameter guesses and pasted numeric
observations. Objective/Jacobian work is compiled through the existing native
fitting engine; live history uses its existing OutputFcn observation interface.

Discovery offers one selected real parameter interval with an explicit sample
count, complete flat real initial-state rows, a run cap and optional checkpoint,
resume and explicit overwrite choices. Preflight generates discoverplan without
running the ensemble. Completed results support stable run-ID replay, sampled
status filtering and numeric CSV/XLSX export. Candidate status names are finite-
horizon evidence, not claims of certified boundedness, periodicity or chaos.

Generate Script checks a complete accepted program without evaluating expressions
or compiling callbacks. Numeric controls reject injected statements/file access.
Save Script writes the current checked program; it defaults to fresh files. A GUI
overwrite confirmation records and rechecks the previous raw file hash, preserving
external changes. Research scripts explicitly clear the numerical workspace after
the algebra directive; they leave source files intact. A changed algebra context
uses Studio's transactional leading-clear behavior. Every source ends in ';' so
console execution and source SHA256 provenance remain identical.

Status/export/replay is tied to the exact submitted UTF-8 source hash. Editing
controls during a run labels its result stale, while Review snapshot retains the
exact completed source. An unrelated execution also invalidates cached panel
freshness. Recompute before exporting current settings. Old valid checkpoint
files are not silently overwritten when model/settings fingerprints change.

The first four example .p files were generated by the same source builder used in
the panel: real_oscillator.p, finite_time_chaos.p, native_curve_fit.p and
oscillator_parameter_sweep.p. pentarnion_bracketing_ode.p additionally generates
the first-paper bracket-controlled Pentarnion model with every coordinate plotted;
its ordered B*(p*p) and (B*p)*p expressions remain distinct. These examples use existing public language commands and can
be inspected, edited, saved and run through the same CLI numerical core. Figure
statements require Studio or the explicit headless figure mode. Generated scripts
retain all coordinates even when one diagnostic projection is displayed.

Additional checked native modes:

PDE: real/Pentarnion1D FD or P1 FE, and2D FD, with explicit RK4 or IMEX Euler
(implicit diffusion, explicit reaction). Boundary choices are constant Dirichlet,
homogeneous Neumann or periodic; periodic axes exclude their duplicate endpoint.
Initial-profile and reaction expressions compile to cached native functions with
runtime parameter/domain values. The mode retains every coefficient, creates
stored-field plots and bounded animation, and exports t followed by each real
coefficient's complete spatial columns. PDE tolerances from the ODE tab are
inactive; refine the explicit integration/discretization settings appropriately.

Geometry: parameterized real3/real5 or Pentarnion surfaces, complete stored
vertices, explicit one-based plot projection, native mesh area and center-chart
curvature/metric diagnostics. The metric is explicitly induced Euclidean geometry;
no unique R5 normal or enclosed3Dvolume is invented. Export writes all embedding
coordinates. Projection/grid/amplitude changes do not discard hidden coefficients.

Mechanics: one real configuration degree of freedom, with a Newton force and
Verlet/RK4, a scalar Lagrangian and generated Euler-Lagrange equations/RK4, or a
Hamiltonian and implicit midpoint. Initial velocity and canonical momentum are
distinguished in both controls and source. Newton's energy panel is kinetic
energy only. L/H energy is defined by the supplied physical scalar. Native
analytic derivatives are generated automatically. Export retains t,q,v,p.

Opening a mode never solves, meshes, compiles or saves source. Generate checks
source without evaluation. Explicit Preflight in these modes prints the checked
plan without integration/mesh evaluation; Run uses the same existing worker.

The seven additional *_explorer.p files were generated by the same source
builder, checked and executed: real/Pentarnion PDEs, R3/R5 geometry, and all three
mechanics forms. Spatial controls are scrollable; editing a custom profile does
not cause hidden execution. The ODE state table is disabled for these modes;
the parameter table remains their shared source of runtime native parameters.

Bounds: 1..8 ODE states /32 real coordinates,16 parameters, one real discovery
interval,4096 runs, LM/Dogleg fitting; PDE grids3..65 per axis and at most240
frames/500000 coefficients; geometry grids3..51 per axis; mechanics is one real
configuration degree of freedom. Larger/multifield/constrained mechanics and
richer data import/multidimensional visual sweep controls remain extensions.
All numerical work uses public native language APIs, without a GUI-only solver.
