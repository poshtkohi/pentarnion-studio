STUDIO DESKTOP DEMO

Open project.pprj, then Run File (F5). It creates two small vector figures.
Use Arrange to split/tab them, Undock to float one, and Tile in Studio for a
visual grid. Existing plot data, camera and labels remain attached to each view.
Save/Load arrangement stores placement; export saves image/vector results.

Double-click observations.csv in the project tree to open its workbook page.
Edit a cell or paste a rectangular selection, undo/redo, then use Save or Save As.
The data page is separate from the Scripts page and is not executed by Run File.
New workbooks can be saved as XLSX. Formulas are stored without recalculation.

Switch View > Interface > Classic/Ribbon. Try F1 on plot3, or search local Help.
Copilot remains optional; only explicit Send contacts a configured provider.
See ../../docs/STUDIO_GUI_GUIDE.txt for limits and detailed desktop controls.

GUI refinement walkthrough:
1. Run this small example to create its two named figures. Drag a figure title
   onto the other figure: the center preview makes tabs; an edge preview splits
   that cell in half. Existing plotted data and view state stay attached.
2. Open Copilot from View. Resize the Figures area: Copilot keeps its independent
   right column, with Command Window on the left. A provider is unnecessary for
   this layout demonstration.
3. Undock a figure or the entire Figures pane. Its native window provides
   minimize/maximize/restore; use Dock to return it. Close all in Figures closes
   the figure views and retains source documents and workspace variables.
4. Use Ctrl+F to open the modeless Find/Replace tool and continue editing. Choose
   Help > Language Reference for formatted topics, syntax and examples.
5. Press Ctrl+Alt+S to select a Studio snapshot, then Copy or Save PNG. File >
   Close All Documents preflights unsaved documents; Cancel retains their tabs.
   Save All now has the distinct shortcut Ctrl+Alt+Shift+S.

This walkthrough describes interactions, not an automatic desktop stress test.

Selection and About: click alternate figures/subplots to see the blue figure
and subplot perimeters, then move the mouse away; the selection remains. Resize
a tiled layout to check its divider handles stay between plots. In About, both
authors have Dr titles and blue email links; all five banner basis labels remain
visible. Activating an email link opens your mail application for composing mail.
