Run real_reaction_diffusion.p for a real logistic field, pentarnion_coefficient_fields.p for five coefficient fields, or heat_equation_check.p for a headless continuum heat-mode check. pdesolve2(reaction,x,y,initial[,options]) requires uniform axes and a ny-by-nx initial matrix. Reaction starts (state,time,x,y[,parameters]) and is cached native code; parameters/options reuse an unchanged body. Values are time-by-(nx*ny), with x changing fastest. pdeslice(field,time_index[,coefficient]) returns a ny-by-nx matrix; time indices are one based and optional coefficient indices are 0..4. All five Pentarnion coefficients are retained when no coefficient is requested. Use pdeslice output directly with imagesc or surf.

Both axes share the chosen boundary: periodic (omit repeated endpoint), homogeneous Neumann, or one constant real/Pentarnion Dirichlet boundary_value on every edge. Axis diffusion_x/diffusion_y may differ; diffusion supplies their shared default. Limits: 3..256 nodes per axis, at most 16384 spatial nodes, bounded retained fields/work/time. Only structured 2D FD is supported here; unstructured 2D FE, mixed/per-side or time-dependent boundaries, nonlinear diffusion and surface PDEs remain future work. Reactions/spatial RK4 operators use Studio's shared CPU budget. IMEX sparse factorization and solves remain serial.
