Open project.pprj in Studio and Run main.p.

The example demonstrates typed functions, ordered Pentarnion products, ranges,
slicing/end, array operations, conditions/loops, reductions, assertions, seeded
random values, help and workspace inspection. It plots a damped oscillation.
Use Data Cursor to pick several points, select a tip and press Delete, or clear
tips with its toolbar/context controls. Source Print/Ctrl+P opens the page preview.

Explicit execution writes samples.csv, samples.xlsx and experiment.pws beside
the project. XLSX contains the numeric time/value table on sheet Trajectory.
The native workspace stores selected full Pentarnion/array values. Run never
needs Microsoft Excel. Checking alone never creates data files.

Existing paper1-bracketing source and numerical parameters are unchanged.
See LANGUAGE_TOOLS_GUIDE.txt at the source root for precise syntax and bounds.
