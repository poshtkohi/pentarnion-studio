NATIVE ANALYTIC THIRD DIRECTIONAL DERIVATIVES

Run any .p file from this project in Studio. Each example fits the default
execution budget. The first request compiles a cached native DLL/SO through
the existing checked scalar callback emitter; later unchanged bodies reuse it.

real-trilinear-derivative.p
  Mixed real polynomial/transcendental derivative and fixed runtime parameters.

one-element-calculus-at-the-origin.p
  Whole-Pentarnion exp/sin, including the smooth radial limit at a real element.

ordered-pentarnion-products.p
  Separate a,b,c inputs demonstrate preserved nonassociative bracketings.

The report contains flattened real coordinates: each Pentarnion contributes
(1,i,j,k,ell). The commuting derivative directions describe real-coordinate
calculus. They do not permit reassociation of the underlying algebra products.
This bounded API returns one D3f[u,v,w] product, not a full derivative tensor or
a general array-state callback. It has no finite-difference production mode.
See specs/third_derivatives_v0_2.txt for domains, budgets and callback limits.
