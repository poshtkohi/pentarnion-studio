Open project.pprj and run compare_serial_parallel.p. It compares identical native Pentarnion PDE bodies with threads=1 and threads=4, verifies every retained coefficient exactly, and prints timings and requested/granted/used workers. The default threads option inherits Studio's parallel settings; 0 means bounded automatic selection. Native callers may request a per-call cap; calls already inside the shared numerical worker pool remain serial to avoid oversubscription. Reaction and FD spatial work are parallel. Existing P1 FE assembly and independent component mass solves can use workers; factorization remains serial. Tiny problems may be slower with multiple workers.
