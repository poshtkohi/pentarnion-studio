Open project.pprj and run implicit_diffusion.p. pdesolve(...,options(integrator="imex_euler")) applies explicit local reaction and implicit linear diffusion using FD or P1 FE consistent mass. This is a first-order IMEX method: reduce time_step to improve accuracy. It removes the diffusion CFL restriction, but does not remove an explicit stiff-reaction restriction. One sparse factorization is reused while the actual time step is unchanged and across coefficients; sparse factorization/solves remain serial. RK4 is still the default, and retains its original explicit stability checks. This is not BDF, fully implicit nonlinear reaction solving, or an adaptive integrator.
