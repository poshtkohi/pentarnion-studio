PENTARNION STUDIO — ORIGINAL VECTOR IDENTITY

The five outer vertices evoke the five Pentarnion coordinates. Four flowing
inner arcs evoke the four quaternion coordinates. The central P stays clear
at small icon sizes. This is a visual identity, not a multiplication diagram.

Master: pentarnion-studio.svg, using geometric paths and gradients without
fonts, linked images, external assets or third-party marks. Transparent PNGs
are rendered directly from that master at each supplied size. The Windows ICO
contains independently rendered 16, 24, 32, 48, 64, 128 and 256 pixel PNG frames.

Qt resources supply the cross-platform application/window/About icon; the
Windows RC resource supplies the executable's Explorer/taskbar icon. Explicit
resource initialization supports statically linked IDE/test targets.
