LANGUAGE
- Version 0.2 adds display(expr[,expr...]); as a top-level statement. At least
  one argument is required. String literals may appear as display arguments for
  labels, as well as in use_algebra; no declared string type or string arithmetic.
- display prints arguments separated by one space, followed by a newline.
  Scalar/element/range-descriptor values are printable; no range enumeration.
- Preserve the original integer/real/pentarnion and integer/real range types,
  promotions, arithmetic, builtin signatures, precedence and grouping checks.
- Empty statements may precede use_algebra; it must remain the first nonempty
  statement. Gamma is a finite signed literal in [0,1], immutable per run.
- Parse and type-check the full source before evaluating any statement.
- Unsupported loops/general functions/imports/arrays/parallel constructs are
  diagnosed. Native ODE models are pure and compiler controlled (L23-L26). No
  arbitrary source shell/filesystem/network/plugin/process access is introduced.

VERSIONS
- New projects use language_version="0.2". Existing 0.1 manifests remain editable
  and statically checkable, without silent metadata changes.
- Interpreter execution requires 0.2; provide an explicit Project action to
  upgrade only project metadata safely. Standalone files default to 0.2.
- display is a 0.2 builtin; checker 0.1 reports it as unsupported.
- A_gamma_v1 is unchanged. Project schema_version remains 1.

EXECUTION
- Each explicit Run File/CLI execution creates a fresh environment and uses an
  immutable source/context snapshot. Never execute on opening, saving or typing.
- Execution order follows the AST exactly; explicit Group nodes survive parsing.
- Mathematical/runtime failures stop that run with a source diagnostic. Output
  already emitted before a runtime failure may be shown; no fabricated success.
- Bound source size, token/AST nesting, statement/operation counts and output;
  cancellation must stop work. One local worker is sufficient; no research
  parallelism. Late results must be labelled/discarded when the source changes.
- Runtime arithmetic detects zero division, integer overflow, nonfinite/domain
  errors and rejected equation solves. No silent pseudoinverse result.
- Integer ranges use checked scalar fields; real fields finite, step nonzero.
  Display a descriptor; do not allocate or enumerate a range.
- Display formatting is locale independent (15 significant digits for binary64),
  preserving all nonzero coefficients; formatting never changes numeric values.

UI / CLI
- Check File / Check Project share the same Qt-free frontend as penta-check.
- Run File / penta-run use the same interpreter and numerical algebra core.
- A read-only Results dock shows display output and run status. A Problems dock
  shows severity/code/file/line/column and navigates correctly through UTF8/UTF16.
- Run first saves the source and captures its saved snapshot, using project default context or file
  directive. Project files remain independent scopes. Stop cancels current work.
- Keep original author/affiliation/contact branding and source safety features.
