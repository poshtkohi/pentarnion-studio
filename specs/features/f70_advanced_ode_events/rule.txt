Authorized extension,26 October2026.

Retain native internal-step polynomials for deval; legacy sample Hermite remains explicit. Nonuniform outputs, controls/statistics/transient windows and constant nonsingular real-coordinate mass matrices are bounded. Singular DAEs/reset assumptions reject; persistence preserves dense/event/backward data.

Hermite, matching each fixed table's q-1 degree. CVODES remains native variable
order. Legacy/dense_output=0 sample interpolation remains cubic Hermite and
depends on stored sample spacing. Native samples and retained polynomial
evaluation agree without reducing the established reference accuracy.

ExecutionOptions.maxRetainedSolutionCoordinates and SolveOptions.maxRetainedCoordinates
default to32M for states/slopes/times/sensitivities/events/polynomial coefficients.

bounds; combined-cap failures preserve the previous workspace. No new .p option
is implied by these host controls. Dense RHS evaluations preserve domain,
timeout and cancellation diagnostics.
