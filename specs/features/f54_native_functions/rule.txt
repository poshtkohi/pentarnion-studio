F54: Restricted native scalar functions and structural cache
Authorized extension, 26 October 2026. Language 0.2.

native function real cube(real x){return x*x*x;} validates in Check without
compilation and compiles in a separate shared-kernel cache on first Run. Runtime
parameters reuse unchanged structure. Support Real/Pentarnion scalar parameters,
results, expressions, typed locals, assignment, if/else and return. Preserve
nonassociative grouping, finite/domain errors, cancellation and bounded work.
Unsupported loops, arrays, complex values, callbacks, records, imports, IO,
captures, helper calls and multiple outputs diagnose with no silent fallback.
Require a configured project/source cache. Exclude build time from tic/toc.

Acceptance: native_function_tests and foundation_language_tests; language-foundations native
cube example. Verify cache reuse, parameter changes, invalid subsets and errors.
Out of scope: general .p JIT, native arrays and compiler-generated parameter AD.
