GTG CELL STUDIO COMPONENT ADAPTATION
31 October2026

Source: GTG Cell Studio/code/src/ide in the user-owned Desktop framework.
These reusable Qt-only components were adapted for Pentarnion Studio at the
user's explicit request. Original GTG sources were not changed.

Adaptations: penta::desktop namespace and include paths, application-neutral
property names, Pentarnion source/project/file icons and command classification.
No GTG scientific model, solver, credentials or user settings are imported.

worker-count adapter observes Pentarnion's existing CPU pool and optional BLAS

retained inside their docking groups. The original GTG files remain read-only.
